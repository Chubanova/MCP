# Ручная установка Node.js и зависимостей для MCP-сервера

## Установка Node.js

1. Перейдите на официальный сайт Node.js: https://nodejs.org/
2. Скачайте LTS версию Node.js для вашей операционной системы (рекомендуется версия 18.x или выше)
3. Запустите установщик и следуйте инструкциям мастера установки
4. После установки перезапустите терминал/командную строку

## Проверка установки

После установки проверьте, что Node.js и npm установлены корректно:

```bash
node --version
npm --version
```

Вы должны увидеть номера версий без ошибок.

## Установка зависимостей проекта

После установки Node.js, перейдите в директорию проекта и установите зависимости:

```bash
npm install
```

## Настройка переменных окружения

Создайте файл `.env` в корне проекта на основе файла `.env.example`:

```bash
cp .env.example .env
```

Откройте файл `.env` и при необходимости измените значения переменных.

## Запуск MCP-сервера

После установки зависимостей вы можете запустить сервер:

```bash
npm start
```

Или в режиме разработки с автоматической перезагрузкой:

```bash
npm run dev
```

## Тестирование работы сервера

Для тестирования работы сервера можно использовать примеры из файла `docs/testing-examples.md`. Логи работы сервера выводятся в stderr и содержат информацию о вызовах инструментов.

## Решение возможных проблем

1. Если команда `npm` не распознается, убедитесь, что путь к Node.js добавлен в переменные окружения PATH
2. Если возникают ошибки при установке зависимостей, попробуйте очистить кэш npm:
   ```bash
   npm cache clean --force
   ```
3. Если сервер не запускается, проверьте, что все зависимости установлены корректно:
   ```bash
   npm list
